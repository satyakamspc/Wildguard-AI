---

name: backend
description: The Backend serves as the central orchestrator of the Wildlife AI Agent system. It receives requests from the frontend, validates and processes uploaded images, coordinates communication between AI agents and external services, manages the overall workflow, and returns structured analysis results to the frontend.

# responsibilities

* Expose REST API endpoints for the frontend.
* Receive and validate uploaded wildlife images.
* Store temporary files when necessary.
* Invoke the AI/ML inference pipeline.
* Coordinate communication between all AI agents.
* Retrieve and aggregate results from each agent.
* Handle errors, retries, and unexpected failures.
* Return structured JSON responses to the frontend.
* Maintain application configuration and environment variables.
* Log requests and system events for debugging.

## inputs

* Image uploads from the frontend.
* API requests.
* Responses from the AI/ML module.
* Outputs from all AI agents.

## Outputs

* Structured JSON responses.
* Analysis status updates.
* Error messages.
* Final wildlife identification report.

## dependencies

* FastAPI.
* AI/ML Module.
* Agent Framework.
* Database.
* File Storage.
* Environment Configuration.

## constraints

* Never expose API keys or sensitive credentials.
* Validate all incoming requests.
* Handle failures gracefully without crashing the system.
* Do not modify factual outputs generated by verified AI agents.
* Ensure secure communication between all system components.

## success criteria

* Successfully receives frontend requests.
* Correctly orchestrates the AI workflow.
* Returns accurate and complete responses.
* Maintains reliable and secure API communication.
* Handles invalid requests and server errors appropriately.
